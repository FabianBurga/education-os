# M2 Product Acceptance Gate

Required before opening M3:

- Academic configuration can be created without hard-coded Ecuador grade labels.
- A section belongs to one period, campus and grade.
- A curriculum plan belongs to one period and grade.
- A course offering binds one section to one subject.
- A teaching assignment binds staff to a course offering.
- An enrollment can have only one ACTIVE section assignment at a time.
- Schedule slots enforce weekday and time consistency.
- Tenant isolation is enforced at database level.
- CI is green.
