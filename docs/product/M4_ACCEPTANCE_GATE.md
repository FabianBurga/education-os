# M4 Product Acceptance Gate

Rector workflow:

1. abrir dashboard;
2. comprender salud institucional sin navegar tablas transaccionales;
3. detectar áreas que requieren atención;
4. bajar a sección/grado;
5. revisar señales explicables;
6. resolverlas manualmente o dejar pendientes;
7. nunca ejecutar una sanción automática desde inteligencia.

M5 podrá convertir señales aprobadas en tareas, comunicaciones y seguimientos.
