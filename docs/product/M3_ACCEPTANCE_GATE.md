# M3 Product Acceptance Gate

Teacher workflow:
1. identificar oferta académica;
2. abrir/crear sesión;
3. registrar asistencia del roster;
4. crear evaluación;
5. registrar calificaciones;
6. mantener registros aislados por institución y sección.

M3 se considera funcional cuando estas operaciones existen en API, están protegidas por
RLS y pasan pruebas de integridad relacional.
