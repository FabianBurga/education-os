# ADR 0028 — M7 release-candidate hardening

Status: Accepted.

M7 prioriza hardening y evidencia operativa sobre nuevas features.

Se fortalecen:
- aislamiento tenant;
- seguridad del runtime role;
- readiness;
- recuperación;
- regresión de contratos;
- runbooks para piloto.

La salida es `v1.0.0-rc1`, no `v1.0.0`.
