# ADR 0029 — Persisted pilot readiness evidence

Status: Accepted.

Cada institución puede ejecutar un `PilotReadinessRun`.

El resultado persiste:
- PASS / FAIL;
- total de checks;
- checks aprobados/fallidos;
- reporte JSON;
- ejecutor;
- timestamp.

La evidencia técnica apoya una decisión humana Go / No-Go.
