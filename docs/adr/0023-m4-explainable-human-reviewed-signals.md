# ADR 0023 — Explainable, human-reviewed intelligence signals

Status: Accepted for v0.5.0.

## Decision

Education OS puede detectar patrones y convertirlos en señales de atención, pero:

- cada señal muestra la métrica y el umbral;
- cada señal tiene una explicación textual;
- la señal no equivale a una sanción ni diagnóstico;
- no existe decisión automática de alto impacto sobre menores;
- una persona autorizada revisa y resuelve;
- M5 podrá automatizar notificaciones/tareas, no decisiones punitivas.

Las reglas iniciales son determinísticas para facilitar auditoría y validación institucional.
