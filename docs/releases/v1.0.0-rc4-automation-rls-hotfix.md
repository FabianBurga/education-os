# Education OS v1.0.0-rc4 — Automation RLS hotfix

## Trigger

Controlled pilot on `v1.0.0-rc3` exposed a real application defect during the
human Automation task lifecycle.

`acknowledge_task()` committed the task successfully, then failed at
`session.refresh(task)`.

## Root cause

Education OS tenant/user RLS context is transaction-local. Internal service
`commit()` ended the transaction and cleared the active `set_config(..., true)`
values. A subsequent ORM refresh therefore queried the row without the required
RLS context.

The diagnostic reproduced:

- visible before commit: 1;
- visible after commit without context reapply: 0;
- visible after context reapply: 1.

## Fix

Automation Service now restores organization, institution and user RLS context
after its internal commit and before refreshing the task in:

- `acknowledge_task`;
- `complete_task`.

## Database

No migration. Alembic remains `0008_m7`.

## Pilot state

The partial `ACKNOWLEDGED` task created during defect discovery is preserved.
The rc4 verifier resumes it and completes it through the real M5 service.

## Release procedure

Do not rewrite rc3. Commit this hotfix, push, wait for CI green, then tag rc4.
