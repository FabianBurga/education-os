# v1.0.0-rc5 — Systemic RLS/runtime hardening

The rc4 internal full-system pilot reproduced a systemic transaction-local RLS
problem beyond Automation: tenant settings vanished after service-layer commits,
causing subsequent `refresh()` calls to lose visibility of the just-written row.

rc5 makes tenant context a Session property and automatically reapplies it at
every SQLAlchemy transaction begin. It also types auth/access UUID parameters,
allows read-only runtime access to `alembic_version` for Pilot Readiness, and
registers Audit foreign-key model targets when Audit is imported standalone.

The integral test harness also corrects its escalation fixture: both `due_at`
and `escalate_at` are moved into the past while retaining `due_at < escalate_at`.

Do not tag rc5 until local verification, the corrected full-system pilot and
GitHub CI are all green.
