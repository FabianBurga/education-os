# Education OS v1.0.0-rc3 candidate — Family Portal UUID hotfix

Discovered during the M7 synthetic pilot.

## Problem

Raw SQL filters in Family Portal received UUID identifiers as Python strings.
SQLAlchemy inferred VARCHAR bind types, causing PostgreSQL to reject comparisons
such as:

`uuid_column = varchar_parameter`

## Fix

Family Portal SQL UUID predicates now explicitly cast identifier bind parameters
to PostgreSQL UUID.

No database migration is required. Alembic remains `0008_m7`.
