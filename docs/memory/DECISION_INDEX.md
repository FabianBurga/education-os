# Accepted decisions and open decisions

## Accepted

- M28 v0.28.0 is the immutable canonical baseline at
  `c21e7c1287a8bc7abd8f355aa619e67c0beee0c4`.
- M29 scope is teacher/family continuity over existing authorities; M29-0 adds
  no product behavior or migration.
- Guardian relationship does not imply portal access; explicit active
  guardian/student grant is required.
- Reuse M13 communications, M20 offline protocol, M18 event ledger, M21
  interventions/timeline and M27 accountability. No parallel backend/engine.
- Families do not receive timeline/intelligence wholesale; no offline client
  direct dispatch; human publication/decision boundaries remain.
- A0 alone owns integration, canonical memory, Git mutation, migration
  authorization and PASS/HOLD. Security review defaults read-only.
- Single-writer file ownership per wave; nested agents prohibited; maximum three
  concurrently active delegated agents.
