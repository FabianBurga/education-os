# Education OS — Pilot Runbook

## Pre-pilot

1. Suite completa verde.
2. `alembic current` en `0008_m7`.
3. Security baseline PASS.
4. Pilot readiness ejecutado.
5. Backup creado y hash verificado.
6. Restore ensayado en una base separada.

## Flujos del piloto

- matrícula;
- estructura académica;
- asistencia;
- calificaciones;
- Rector Intelligence;
- Automation Case / Task;
- Family Portal;
- aviso familiar + acknowledgement.

## Stop conditions

Detener el piloto si aparece:
- acceso cross-tenant;
- guardian accede a estudiante no autorizado;
- pérdida o corrupción de datos;
- restore no recuperable;
- decisión punitiva automática;
- issue P0/P1 de seguridad.

## Go / No-Go

Promover a v1.0.0 solo con evidencia técnica + aceptación de usuarios piloto.
